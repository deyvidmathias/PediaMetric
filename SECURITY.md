# Security policy

PediaMetric has not published a stable release yet. Security fixes are applied
to the current development branch; no older version is currently supported.

Do not open a public issue for a vulnerability, exposed credential, or privacy
problem. After the GitHub repository is created, use GitHub Private
Vulnerability Reporting from the repository's **Security** tab. Until that
channel is enabled, do not transmit sensitive details through public project
channels.

Reports should include the affected component and version, reproduction steps,
impact, and a minimal proof of concept that contains no patient information.

PediaMetric processes measurements locally. A change that sends, persists,
logs, or places clinical input in a URL is considered a security and privacy
regression.
