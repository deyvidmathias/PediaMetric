# Security Policy

## Current status

`@pediametric/core` is private and unpublished. There is no public security-reporting channel yet and no supported public release.

## Reporting a vulnerability

When the future GitHub repository enables Private Vulnerability Reporting, use that feature to report vulnerabilities confidentially. Include:

- the affected version or commit;
- a concise description and potential impact;
- reproducible steps or a minimal proof of concept;
- any suggested mitigation, if known.

Do not disclose a suspected vulnerability in a public issue, discussion, pull request, or social-media post. Before any public release, the maintainers must enable and test a private reporting channel and update this document with the repository-specific process. No email address is listed because a monitored security mailbox has not been established.

## Scope

Relevant reports include incorrect boundary behavior, unsafe input handling, dependency or packaging issues, unexpected network or storage access, and flaws that could silently produce materially incorrect results.

Clinical disagreements that do not involve a security or integrity defect should use the normal contribution process and cite primary evidence.

## Response expectations

Response times and supported-version windows will be published when a maintained public release exists. Until then, this document is preparation guidance and does not promise a service level.
