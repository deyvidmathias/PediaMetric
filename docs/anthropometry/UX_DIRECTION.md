# Direção futura de interface

Esta etapa não implementa UI.

Requisitos registrados para a etapa posterior:

- aparência moderna e tecnológica;
- movimentos e microinterações com respeito a `prefers-reduced-motion`;
- linguagem visual médica, limpa e confiável;
- referências pediátricas sutis, sem infantilização excessiva;
- fluxo simples `Dados -> Medidas -> Resultados`;
- curvas dinâmicas derivadas dos mesmos LMS do motor;
- ponto de integração para logo PNG a ser fornecida pelo usuário;
- nenhuma coleta, telemetria ou persistência automática de dados clínicos.
